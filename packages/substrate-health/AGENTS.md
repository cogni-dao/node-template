# substrate-health

Published `@cogni-dao/substrate-health` owns the node-neutral deep-readiness mechanism every Cogni node's `/readyz?deep=1` is built from.

Public surface (`.`): `runDeepChecks` (concurrent, bounded, emits one `substrate.deep.complete` per-dependency summary via an injected `log`, throws `DeepProbeFailure`), `DeepProbeFailure`, the reach-probe factories `probeRedisStream` / `probeKnowledgePlane` (take a PORT OBJECT and call its method, so a class keeps `this`) and `probeLiteLlmGateway` (`{baseUrl, apiKey, budgetMs}`), the declaration-map type `SubstrateDependency` (plus `ProbeDependency` / `NaDependency` / `SubstrateDependencyBase`), and the env-schema drift guard `findUnclassifiedSubstrateKeys` + `SUBSTRATE_ENV_KEY_PATTERN`.

Leaf package: no app, container, env-loader, framework, DB or Temporal imports. A node injects its logger, its connectivity error type (`DeepRuntime.timeoutError`, `ProbeOptions.wrapError`), the per-check budget, its ports, and its own declaration map + env closures. A node keeps local: the route, env loading, container wiring, the declaration-map data, the EVM/Temporal/scheduler-worker/Postgres closures, and any non-deep (default) path. The probe-name union, the summary event name `substrate.deep.complete`, the 503-nameable dependency set and the drift-guard pattern are a published contract: changing any is a version bump. Prove packed JavaScript and declarations in a clean consumer.
