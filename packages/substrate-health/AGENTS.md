# substrate-health

Published `@cogni-dao/substrate-health` owns the node-neutral deep-readiness mechanism every Cogni node's `/readyz?deep=1` is built from.

Public surface (`.`): `serveReadyz` (the whole `/readyz` response, framework-free: a default path that runs only the node's local config check and makes ZERO remote calls, plus the registry-driven deep path; nodes wrap its `{status, body}` in their HTTP framework), `runDeepChecks` (concurrent, bounded, emits one `substrate.deep.complete` per-dependency summary via an injected `log`, throws `DeepProbeFailure`), `DeepProbeFailure`, the reach-probe factories `probeRedisStream` / `probeKnowledgePlane` (take a PORT OBJECT and call its method, so a class keeps `this`) and `probeLiteLlmGateway` (`{baseUrl, apiKey, budgetMs}`), the declaration-map type `SubstrateDependency` (plus `ProbeDependency` / `NaDependency` / `SubstrateDependencyBase`), the env-schema drift guard `findUnclassifiedSubstrateKeys` + `SUBSTRATE_ENV_KEY_PATTERN`, and the deep HTTP body contract: `runDeepChecks` returns the `DeepChecks` map (also carried on `DeepProbeFailure.checks`); a node puts `checks` in its deep 200 and `checks` + `unreachable` + `buildSha` in its deep 503 (`DeepReadyzEvidence`). `readDeepReadiness(status, body)` is the ONE reader every consumer (operator KPIs, DB recovery, flight gates) uses: a dependency is `reached` only on positive `checks[name].status === "ok"`; a body without `checks` is `unknown`, never green.

Leaf package: no app, container, env-loader, framework, DB or Temporal imports. A node injects its logger, its connectivity error type (`DeepRuntime.timeoutError`, `ProbeOptions.wrapError`), the per-check budget, its ports, and its own declaration map + env closures. A node keeps local: the route, env loading, container wiring, the declaration-map data, the EVM/Temporal/scheduler-worker/Postgres closures, and HTTP, lifecycle, environment and logging wiring for the default path. The reusable default response policy remains in `serveReadyz`. The probe-name union, the deep body fields and reader semantics, the summary event name `substrate.deep.complete`, the 503-nameable dependency set and the drift-guard pattern are a published contract: changing any is a version bump. Prove packed JavaScript and declarations in a clean consumer.
